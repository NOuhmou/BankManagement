# 🏦 Bank Management System - Version 1 (Mémoire)

## Description
Première version du système bancaire. Les données sont stockées en mémoire (disparaissent à l'arrêt du programme).

## Fonctionnalités
- ✅ Création de comptes avec RIB/PIN auto-générés
- ✅ Dépôt et retrait d'argent
- ✅ Transfert entre comptes
- ✅ Authentification (RIB + PIN)
- ✅ Interface console

## Structure du projet
v1-memory/
└── src/
├── Account.java
├── Bank.java
├── BankEntity.java
├── Client.java
├── Employee.java
├── Main.java

## Concepts Java utilisés
- Programmation Orientée Objet (POO)
- Héritage (`Client extends Person`)
- Interfaces (`BankEntity`)
- Gestion des exceptions
- Collections (ArrayList)
