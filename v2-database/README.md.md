# 🏦 Bank Management System - Version 2 (Avec MySQL)

## Description
Version améliorée avec persistance des données dans une base de données MySQL.

## Nouvelles fonctionnalités
- ✅ Persistance des données (MySQL)
- ✅ Architecture DAO (Data Access Object)
- ✅ Transactions bancaires complètes
- ✅ Gestion professionnelle des connexions

## Base de données

- **Nom** : `bank_db`
- **Tables** : clients, comptes, transactions

## Améliorations par rapport à v1

- ✅ Persistance des données
- ✅ Architecture plus professionnelle
- ✅ Code plus maintenable (DAO)
- ✅ Transactions sécurisées

## Installation

### 1. Installer XAMPP
- Télécharger XAMPP
- Démarrer MySQL

### 2. Créer la base de données
- Ouvrir phpMyAdmin
- Exécuter `creation.sql`

### 3. Ajouter le pilote JDBC
- Télécharger mysql-connector-j-8.0.33.jar
- Ajouter au projet
